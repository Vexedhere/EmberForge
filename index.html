Install a schematic in minutes.

Three steps from your download to a finished build in your world.

Download your file

After checkout, open your delivery from the Tebex confirmation. You'll get the schematic file for your build, usually a .schem file.

Check each product page for the file format and supported Minecraft versions before you buy.

Add it to your server

Upload the file to your schematics folder, then restart or reload WorldEdit.

plugins/WorldEdit/schematics/

Using FastAsyncWorldEdit? The folder is plugins/FastAsyncWorldEdit/schematics/.

Paste it in game

Load the schematic, stand where you want it, then paste.

//schem load your_build
//paste

Add -a to skip air blocks, or run //rotate 90 before pasting to turn the build.
