Custom Dev: your server, built your way.

We start with a conversation. You tell us your server type, your theme and what you want players to experience, and we turn that into a clear plan with scope, timeline and price before any work begins.

Our team then builds in stages: layout and builds first, then plugins and configuration, then a full test on a staging server. You see progress along the way, can ask for changes, and receive everything ready to install, with help getting it live. Custom builds, plugins, rank systems and complete server setups are all handled the same way.

Install a schematic in minutes.

Three steps from download to finished build.

Download your file

After checkout, open your delivery from the Tebex confirmation. You get the schematic file, usually a .schem file.

Check each product page for the file format and supported Minecraft versions.

Add it to your server

Upload the file to your schematics folder, then restart or reload WorldEdit.

plugins/WorldEdit/schematics/

Using FAWE? Use plugins/FastAsyncWorldEdit/schematics/

Paste it in game

Load the schematic, stand where you want it, then paste.

//schem load your_build
//paste

Add -a to skip air blocks, or //rotate 90 before pasting.
