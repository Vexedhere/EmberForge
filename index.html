Command Help

/fly

Toggles flight mode for the player (requires permission).

/feed

Fills the player's hunger bar (requires permission).

/pay

Transfers in-game currency to another player. Usage: /pay [player] [amount]

/craft

Opens a virtual crafting table for the player.

/discord

Displays the server's Discord invite link in chat.

/tpa

Sends a teleport request to another player. Usage: /tpa [player]

/tpaccept

Accepts a pending teleport request from another player.

/tpadecline

Declines a pending teleport request from another player.

/tpacancel

Cancels a teleport request you sent to another player.

/rtp

Teleports the player to a random location in the world.

/shop

Opens the server shop GUI for buying and selling items.

/ah

Opens the auction house to browse player listings.

/ah sell

Lists an item for sale in the auction house. Usage: /ah sell [price]

/coinshop

Opens a shop where items can be purchased with in-game coins.

/pw set

Sets a personal warp point for the player. Usage: /pw set [name]

/warp Crates

Teleports the player to the crates area.

/warp Leaderboards

Teleports the player to the leaderboards area.

/warp PVP

Teleports the player to the PVP arena.

/msg

Sends a private message to another player. Usage: /msg [player] [message]

/back

Teleports the player to their last location (requires permission).

/home

Teleports the player to their set home. Usage: /home [name]

/sethome

Sets a home at the player's current location. Usage: /sethome [name]

/bal

Displays the player's current in-game currency balance.

/kit

Lists or claims available kits. Usage: /kit [name]

/spawn

Teleports the player to the server's spawn point.
