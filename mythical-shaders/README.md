# Mythical Shaders — Verdant Preview

**Version:** 0.1.0-preview  
**Edition:** Minecraft Java Edition  
**Loader target:** Iris Shaders (legacy GLSL compatibility path); compatibility varies by Minecraft version and shader loader.  
**Price:** Free

Mythical Shaders is an original Mythical Studios shaderpack experiment. This first preview focuses on a distinct post-processing look: slightly richer colors, a gentle warm tint, added contrast, and subtle edge shading.

## Current features
- Mythical color grading and contrast.
- Optional vibrance, warmth and vignette settings in the shader settings menu.
- Small, lightweight post-processing pass.
- Source code included in this repository.

## Honest limitations
This is an early visual prototype, not a full path-traced or physically realistic shader. It does **not** yet implement custom dynamic shadows, volumetric clouds, water reflections, or waving foliage. Performance and compatibility have not been tested across every Minecraft version or GPU.

## Install
1. Install a Minecraft Java shader loader compatible with this pack (start with Iris).
2. Download `Mythical-Shaders.zip` from the Mythical Shaders latest GitHub Release.
3. Put the ZIP in `.minecraft/shaderpacks/` without extracting it.
4. Open Minecraft → Options → Video Settings → Shader Packs and select **Mythical Shaders — Verdant Preview**.
5. If it fails to load, share the shader log and Minecraft/Iris version so the pack can be fixed.

## Project status
This is an initial preview. We need in-game testing and feedback before describing it as production-ready. All shader code here is written for Mythical Studios; do not claim compatibility that has not been tested.
