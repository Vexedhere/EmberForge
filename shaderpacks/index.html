Quick setup

Install a shaderpack in a few steps.

This guide is for Minecraft Java Edition. Shaderpacks are not the same as Bedrock RTX packs. Make a note of your game version and install a compatible shader loader first.

Get Iris from its official site ↗
Keep the shaderpack as a ZIP unless its official instructions say otherwise. Never run an unknown executable just to install a shaderpack.
1

Install a shader loader

Install Iris from the official Iris website, or use a compatible OptiFine installation if the pack supports it. Follow the loader's own setup instructions.

2

Download from the creator

Open the official project link above and choose a file compatible with your Minecraft version and loader. Keep the downloaded shaderpack ZIP intact.

3

Open the shaderpacks folder

Launch the correct Minecraft profile, open Options → Video Settings → Shader Packs / Shaderpacks, then use the folder button shown by your loader.

.minecraft/shaderpacks/
4

Enable and tune it

Return to the shader menu, select the pack and apply it. If FPS drops, reduce shadow quality, render distance, volumetric effects or reflections.

Good to know

Before you install.

A few checks help avoid crashes and disappointing performance.

Are these shaderpacks really free?

The listed packs have free downloads from their official project pages. Optional creator support or donations are separate; always read the creator's terms.

Will shaders work on Bedrock Edition?

This directory is for Minecraft Java Edition shaderpacks. Bedrock graphics add-ons and RTX packs are different and are not included here.

Which shader is best for a low-end PC?

Try MakeUp - Ultra Fast first, then lower the shader settings. No pack can guarantee smooth FPS on every computer.

Why do the versions differ?

Each creator releases files on their own schedule. Use the official page to confirm the latest version and loader compatibility before downloading.
