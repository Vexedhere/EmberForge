Setup guide

Get it running in Minecraft.

This is a Minecraft Java shaderpack. It needs a compatible shader loader such as Iris. The pack has not been tested across every game version or GPU yet.

Iris official download ↗
If Minecraft reports a shader compile error, disable the pack and send us the error log with your Minecraft and Iris versions. This preview is still being tested.
1

Install Iris

Use the official Iris installer and follow its instructions for your Minecraft Java version.

2

Download Mythical Shaders

Use the download button above. The ZIP should contain a shaders folder at its root. Do not extract it unless troubleshooting instructions ask you to.

3

Move the ZIP into shaderpacks

Open Minecraft → Options → Video Settings → Shader Packs, then use the folder button to open the shaderpacks directory.

.minecraft/shaderpacks/Mythical-Shaders.zip
4

Enable the pack and tune it

Select Mythical Shaders — Verdant Preview. Open Shader Pack Settings to toggle vibrance, warmth or vignette. If the pack does not appear or fails to compile, share the log so we can fix the first release.

FAQ

Before you try it.

Is this actually made by Mythical Studios?

Yes. The shader source for this preview is being developed in the Mythical Studios EmberForge repository. This is an early original prototype, not a rebrand of another shaderpack.

Is it free?

Yes, this preview is free. The source is available in the public repository.

Does it have realistic shadows and reflections?

Not yet. This first build focuses on post-processing color and contrast. Advanced lighting effects are future work and need real in-game testing.

Will it work with every version?

Not guaranteed yet. Compatibility depends on Minecraft, Iris/other loader versions and hardware. We need testing feedback before publishing a supported-version list.
